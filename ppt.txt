Introduction:

Medical data breaches and identity theft are among leading global cybersecurity threats. Secure patient record access is critical, yet conventional Electronic Health Record (EHR) systems rely heavily on centralized plaintext databases and weak authentication, rendering them vulnerable to cyberattacks. Cryptography-EHR was built to bridge the gap between advanced cryptography and real-world clinical workflows by delivering a tamper-proof, zero-trust, and automated healthcare management platform.

---

Problem Statement:

Modern healthcare demands secure digital records, yet current hospital methods depend on unencrypted, centralized databases vulnerable to instant cyberattacks. Existing healthcare platforms act as easily compromised targets, providing only basic password protection with no internal access compartmentalization, making them highly vulnerable to ransomware and inside threats. Cryptography-EHR addresses these gaps by delivering a strictly role-based, zero-trust cryptographic platform guaranteeing absolute data privacy.

---

Objectives:

1. To develop a highly secure web application that safely stores and encrypts sensitive electronic health records for hospitals and clinics.
2. To implement a dual-layered security approach using AES-256 for data encryption and RSA digital signatures to prevent any unauthorized record tampering.
3. To build a strict, role-based platform that securely separates data access for patients, doctors, pharmacists, and administrators.
4. To create an intelligent symptom mapping feature that helps patients automatically find the most relevant hospital department and specialized doctor.
5. To ensure complete system safety by adding Two-Factor Authentication (SMS OTP) and an automated audit tracking system that alerts administrators during emergencies.

Methodology / Proposed System:

1. Cryptography-EHR securely authenticates users (Patients, Doctors, Pharmacists) into a role-based web portal utilizing synchronous Twilio Two-Factor Authentication (SMS OTP).
2. The system's heuristic engine processes unstructured patient symptoms, automatically mapping them to the most relevant clinic department for immediate triage.
3. Authorized doctors generate highly sensitive clinical prescriptions and diagnostic records natively on their secure HTML5 dashboard interfaces.
4. The Node.js backend executes AES-256-GCM arrays to fully encrypt the data payload and generates an RSA digital signature to mathematically guarantee absolute non-repudiation.
5. The ciphertext is safely stored in MongoDB and decrypted exclusively across role-specific dashboards, while a background Autonomous Logging Service independently tracks usage and dispatches emergency text alerts for any unauthorized breaches.

---

Methodology (System Modules):

Module 1: Authentication & RBAC Engine: Implements severe, role-based dashboards (Patient, Doctor, Pharmacist, Admin) secured by Twilio Two-Factor Authentication (OTP).

Module 2: Heuristic Symptom Mapping: Analyzes unstructured patient symptom inputs into the system to intelligently recommend relevant hospital departments and medical specialists.

Module 3: RSA Signature Module: Utilizes asymmetric cryptographic keys to digitally sign physical reports, mathematically guaranteeing the doctor's identity and clinical non-repudiation.

Module 4: AES-256 Encryption Engine: Employs military-grade symmetric Galois/Counter Mode (GCM) encryption to secure all plaintext medical records into unreadable ciphertexts.

Module 5: SHA-256 Integrity Verification: Generates complex, one-way cryptographic hashes of diagnostic documents to instantly detect and prevent malicious database tampering.

Module 6: Autonomous Audit Service: Dynamically tracks background security variables and dispatches instant Nodemailer (SMTP) and Twilio (SMS) alerts during unauthorized emergency overrides.

Hardware and Software Requirements (Technology Stack):

Software Requirements:
• Programming Language: JavaScript (ES6+), Node.js environment
• Web Framework: Express.js (REST API architecture)
• Cryptographic Engine: Node Standard 'crypto' (AES-256-GCM, RSA-2048, SHA-256)
• Database: MongoDB Atlas (Cloud NoSQL) via Mongoose ORM
• Frontend: React.js, HTML5, CSS3
• Security MFA API: Twilio SMS (Two-Factor Authentication)
• Alerting API: Nodemailer (SMTP for autonomous auditing)
• Authentication: JSON Web Tokens (JWT) & Bcrypt Middleware
• Operating System: Windows 10 / Ubuntu 20.04

Advantages and Applications:

Advantages:
